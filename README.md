# Personal homepage redirect

The personal homepage is maintained and served at https://sugrsertraline.top/.

This repository only redirects the previous GitHub Pages address to that domain. It does not contain a second copy of the personal website or its assets. JavaScript preserves query parameters and section anchors; meta refresh and a normal link provide fallbacks.

The original page and assets remain recoverable in Git history (last full-page commit: d5954d1c5d6fb722486fb10d48ad14314860896f).
